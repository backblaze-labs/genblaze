### genblaze-core

#### Changed

- `Pipeline.run`, `arun`, `map` and `amap` now type
  `on_progress`, `on_step_complete` and `on_retry` as precise callables instead
  of `Any`, and so do the webhook `make_on_progress` / `make_on_step_complete`
  factories. No runtime change; type checkers now flag a callback with the
  wrong signature, including an `async def` (#45).
- the s3 storage backend and the download spool threshold now take
  their pool size, timeouts, retries and multipart sizes from
  `StorageConfig`'s defaults instead of separate copies. Values are unchanged
  (#42).
#### Removed

- the unused `genblaze_core.providers.canonical_params` module and
  the private, never-applied `storage._tracer` decorator. Nothing in genblaze
  imported either. If you imported the canonical name constants, define them
  locally; connectors still accept those parameter names (#47).
#### Fixed

- `PipelineTemplate.instantiate()` now constructs only providers
  referenced by the template during auto-discovery. Unused providers that need
  credentials no longer prevent a valid template from loading. Empty templates
  fail before discovery; explicit provider maps remain authoritative (#67).
- Computed costs no longer carry float noise such as 0.30000000000000004. cost_usd from registry pricing, estimate_cost() and AgentResult.total_cost_usd are rounded to 9 decimal places, preserving sub-micro-dollar per-token rates. Persisted manifests, Parquet rows and canonical hashes are unchanged (#63).
- ModelRegistry now updates its warning-dedup sets under its lock, so a concurrent fork() cannot copy a set mid-change on free-threaded Python. Document the concurrency guarantee (#58).

### genblaze-openai

#### Added

- `SoraProvider(base_url=...)` (keyword-only) to target
  OpenAI-compatible Videos API servers now that OpenAI's own Videos API is
  shut down. `base_url` must be `https://`, or `http://` on a loopback host,
  with no credentials, query or fragment. Discovery now queries the server
  the SDK actually calls (`base_url`, then `OPENAI_BASE_URL`) and keeps every
  slug a compatible server lists; only api.openai.com is filtered to
  `sora-*` (#319).

### Internal

#### Changed

- Generate wave release notes with Changie; require trusted signed tags and closed wave milestones before production publication; bind release candidates to the workflow commit (#354).
- Release dry runs build and twine-check every package without Python uploads; npm runs with --dry-run. TestPyPI is no longer used (#352).
